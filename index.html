This is a visual approximation of the Monkey C face, not Garmin's official simulator. It is useful for checking artwork, hand placement, date placement and AOD appearance before installing the PRG.

Known issue: the current reference-derived dial background still contains portions of the photographed physical hands, so some times can show a ghost/double-hand effect.
