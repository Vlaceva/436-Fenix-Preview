# 436 CC130J — Fenix 8 Preview

Public browser preview for the 436 CC130J Garmin fēnix 8 47 mm AMOLED watch face.

This repository contains **preview-only assets**. The Garmin Connect IQ / Monkey C source project, signing material, and PRG build workflow remain in the separate private repository.

## Preview

Once GitHub Pages deployment completes, the site provides:

- live browser time and date
- manual hour, minute, second, and date controls
- active-display preview
- always-on display preview
- 454 × 454 native canvas rendering
- PNG preview export

The browser renderer is a visual approximation of the Garmin implementation, not the official Connect IQ Simulator.
